# IronPulse Gym — Train Hard, Recover Harder

Live demo site: a fitness gym with working class bookings and a BMI tool.

**What actually works (in your browser, no server needed):**
- Class timetable with real booking buttons (name required)
- Bookings list saved in localStorage, with cancel buttons
- Membership selection with an honest "demo stops before payment" note
- BMI calculator with health-band guidance

**Honest limits:** static front-end. No membership is created and no payment
is taken. Connect a booking/payment system for real signups.
